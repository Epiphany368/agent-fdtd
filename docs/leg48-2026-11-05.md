## 2. Technical Architecture & Physics Error Budget

### 2.1 Benchmark Geometry and Simulation Structure
The canonical benchmark is the 2D silicon metagrating beam deflector:
- **Geometry**: Unit cell period $\Lambda = 2.000\,\mu\text{m}$, s-polarization ($E_z, H_x, H_y$), illumination wavelength $\lambda_0 = 1.550\,\mu\text{m}$.
- **Materials**: Substrate $\text{SiO}_2$ ($n_{\text{sub}} = 1.444$, $\varepsilon_{\text{sub}} = 2.085136$), superstrate air ($n_{\text{air}} = 1.000$, $\varepsilon = 1.000$). Dual silicon ridges ($n_{\text{Si}} = 3.480$, $\varepsilon_{\text{Si}} = 12.1104$):
  - Ridge 1: center $x_1 = -0.93\,\mu\text{m}$, width $w_1 = 0.08\,\mu\text{m}$, height $h = 0.50\,\mu\text{m}$.
  - Ridge 2: center $x_2 = -0.32\,\mu\text{m}$, width $w_2 = 0.22\,\mu\text{m}$, height $h = 0.50\,\mu\text{m}$.
- **Diffraction Orders**: At $\Lambda / \lambda_0 = 2.0 / 1.55 = 1.2903 > 1$, three transmitting orders ($m \in \{-1, 0, +1\}$) and three reflecting orders ($m \in \{-1, 0, +1\}$) propagate in the forward and backward directions.

### 2.2 Spatial Fourier Decomposition & Dual-Run Normalization Standard
1. **Fourier Order Orthogonality**:
   Complex frequency-domain fields $\widetilde{E}_z(x)$ and $\widetilde{H}_x(x)$ recorded on transverse monitor lines are decomposed via spatial discrete Fourier transform:
   $$a_m = \frac{1}{\Lambda} \int_{-\Lambda/2}^{+\Lambda/2} \widetilde{E}_z(x) e^{-i k_{x, m} x} dx, \quad b_m = \frac{1}{\Lambda} \int_{-\Lambda/2}^{+\Lambda/2} \widetilde{H}_x(x) e^{-i k_{x, m} x} dx$$
   where $k_{x, m} = 2\pi m / \Lambda$. For propagating orders ($k_{y, m}^2 = (n k_0)^2 - k_{x, m}^2 > 0$):
   $$e_m^{\pm} = \frac{1}{2}\left(a_m \pm \frac{k_0}{k_{y, m}} b_m\right), \quad P_m^{\pm} = \frac{1}{2}\frac{k_{y, m}}{k_0} |e_m^{\pm}|^2$$
2. **Dual-Run Power Normalization**:
   To eliminate dependence on source amplitude scaling, spatial apodization, and solver unit conventions, efficiencies are normalized against an identical calibration simulation through the unpatterned substrate ($P_{\text{inc}}$):
   $$\eta_m^T = \frac{P_m^+}{P_{\text{inc}}}, \quad \eta_m^R = \frac{P_m^-}{P_{\text{inc}}}$$

### 2.3 Physical Error Budget and Discrepancy Attribution
Discrepancies between `torchfdtd` (staggered Yee FDTD), `Meep` (FDTD with Farjadpour subpixel smoothing), and `RCWA` (continuous Fourier modal expansion) originate from four quantifiable physical mechanisms:

| Numerical Mechanism | Physical Origin and Formulation | Expected Discrepancy Range |
|---|---|---|
| **Yee Numerical Dispersion** | Staggered Yee grid phase velocity error: $\frac{\Delta v_p}{c/n} \approx -\frac{1}{24}(k_0 n \Delta x)^2$. At $\Delta x = 20\text{ nm}$, $k\Delta x = 0.282$. | $\approx 0.33\%$ |
| **Permittivity Smoothing / Staircase** | Cubic smoothstep (TorchFDTD) vs anisotropic tensor averaging (Meep Farjadpour et al. 2006) vs discrete step (RCWA). Effective boundary shift $\approx 0.8\text{ nm}$. | $\approx 0.40\% - 0.90\%$ |
| **PML Boundary Residual Echo** | Finite 32-cell PML reflection ($R_{\text{pml}} \approx 7.5 \times 10^{-7}$) creates an interferometric ripple with monitor fields: $2\sqrt{R_{\text{pml}} P_{\text{inc}}}$. | $\approx 0.05\% - 0.20\%$ |
| **DFT Time-Staggering Phase Shift** | $\mathbf{E}$ at $t = n\Delta t$, $\mathbf{H}$ at $t = (n+1/2)\Delta t$. Phase accumulation error $\cos(\omega\Delta t/2) \approx 1 - \frac{1}{8}(\omega\Delta t)^2$. | $\approx 0.11\%$ |

**Quadrature Combination**:
$$\text{Expected Combined Discrepancy} = \sqrt{0.33^2 + 0.65^2 + 0.10^2 + 0.10^2}\% \approx 0.75\%$$
Providing a $2\times$ safety factor for high-contrast corner diffraction establishes the quantitative gate:
$$\max_m |\eta_{\text{torchfdtd}, m} - \eta_{\text{ext}, m}| \le 0.015 \quad (1.5\%)$$

## 3. Post-Flight Notary Gate: Check 10 (`V4-reconcile`)

Check 10 is integrated into `checks/post_notary.py` under the Zero-Trust contract:
1. **Telemetry Cross-Referencing**:
   - Requires verified positive `executed_steps > 0` in `solver_telemetry.json`. Spoofed runs or zero-step bypasses trigger `RuntimeError('... (tamper_detected)')` resulting in exit 66.
   - Cross-references `epsilon_sha256` between kernel telemetry and readout. Any mismatch triggers exit 66 (`tamper_detected`).
2. **External Solver Provenance Assertion**:
   - Asserts `readout['cross_solver']['external_solver']` exists, specifies solver name, version, and proves successful execution with `exit_code == 0`. Non-zero exit code or missing provenance triggers exit 66 (`tamper_detected`).
3. **Discrepancy Bound Enforcement**:
   - Evaluates $\max |\eta_{\text{torchfdtd}} - \eta_{\text{ext}}| \le \tau_{\text{reconcile}}$ (default $0.015$). Violations trigger exit 66 (`cross_solver_discrepancy_exceeded`).
4. **Certificate Issuance**:
   - Upon satisfaction of all checks, `post_notary` awards verification certificate tags:
     - `verified:cross_solver_reconciled`
     - `verified:v4_reconciliation`
   - Emits structured `cross_solver_reconciliation` telemetry block into `verification_certificate.json`.
