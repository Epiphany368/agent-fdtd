## 1. Context and Problem Statement

Under the Agent-Oriented FDTD Platform v4 architecture (`spec-agent-fdtd-platform-v4.md`, Wave A), the core governance axiom is **Zero-Trust**:
> "Agent 只有'提议权'，没有'自判权'。一次仿真是否可信由启动器与求解器内核生成的不可伪造遥测指纹 + 强制后置物理公证器决定。"

Prior to LEG 44:
1. **Guided Grating Exclusion in `src/invariants.py`**:
   The existing energy balance invariant `V2-a` checked a two-surface balance ($|R + T - 1| \le \text{tol}$) on closed plane cases (`empty`, `slab`, `interface`). Guided grating couplers (N8 and G8) were explicitly excluded from `V2-a` because 1D transmission and reflection ignore out-of-plane cladding radiation ($P_{\text{up}}$) and substrate leakage ($P_{\text{down}}$). On N8 gratings, $T \approx 0.574$ and $R \approx 0.104$, giving $T + R \approx 0.678 \ll 1.0$. Without accounting for the top and bottom surfaces, guided devices could never obtain a `verified` physics label.
2. **Post-Flight Passivity Limitation in `checks/post_notary.py`**:
   LEG 43 introduced a universal passivity gate enforcing $\sum P_{\text{out}} \le 1.0 + \tau_{\text{pml}}$, but this only tested an inequality (no power creation). An unclosed enclosure or missing leakage monitor (e.g., omitting substrate leakage $\approx 0.0363$) satisfied passivity unchecked.
3. **Hardcoded Post-Flight Status in `tools/launch.py` and Notary**:
   When post-flight verification failed, `tools/launch.py` and `checks/post_notary.py` hardcoded the failure status to `'failed:postflight=tamper_detected'`, obscuring whether failure was caused by insufficient simulation time (`under_converged_time`), incomplete enclosure (`poynting_box_unclosed`), passivity violation (`passivity_violation`), or actual file tampering.
4. **Certificate Schema Completeness**:
   `verification_certificate.json` lacked explicit recording of box closure residual ($R_{\text{box}}$) and decay ratio ($E(T_{\text{end}})/E_{\max}$).

## 2. Technical Implementation

### 2.1 Guided 4-Surface Poynting Enclosing Box (`V2-box`) in `src/invariants.py`
1. **Registration in `IDS`**:
   Expanded active invariant IDs in `src/invariants.py`:
   ```python
   IDS = ('V2-a', 'V2-b', 'V2-c', 'V2-d', 'V2-box')
   ```
2. **Lawfulness Check (`_lawful`)**:
   Enforced that `V2-box` is lawful on lossless structures where a 4-surface enclosure or guided grating is declared (`physics['lossless'] is True`), while rejecting lossy media.
3. **Monitor Surface Extraction (`_box_quad`)**:
   Extracted the four bounding surfaces across standard aliases:
   - **Right face**: `box-right`, `box_right`, `transmission`, `trans`, `far`, `T`, `right`
   - **Left face**: `box-left`, `box_left`, `reflection`, `refl`, `near`, `R`, `left`
   - **Top face**: `box-top`, `box_top`, `top`, `up`, `cladding`
   - **Bottom face**: `box-bottom`, `box_bottom`, `bottom`, `down`, `substrate`
   Handles scalar and wavelength-dependent spectral arrays. Records JSON leaf paths into `row['covers']`.
4. **Conservation Arithmetic**:
   Computes:
   $$\Phi_{\text{out}} = |\Phi_{\text{trans}}| + |\Phi_{\text{refl}}| + |\Phi_{\text{up}}| + |\Phi_{\text{down}}|$$
   $$R_{\text{box}} = \left| \frac{\Phi_{\text{out}}}{\Phi_{\text{inc}}} - 1 \right|$$
   Where $\Phi_{\text{inc}}$ defaults to $1.0$ (or extracted from `P_in` / `incident_power`).
   Enforces $R_{\text{box}} \le \text{tolerance}$ (typically $10^{-5}$). Stored `box_closure_residual` is verified for bit-exact consistency before trust is granted.

### 2.2 4-Surface Box Closure and Decay Gates in `checks/post_notary.py`
1. **Automatic Detection of 4-Surface Box Enclosure (`_detect_4surface_box`)**:
   Detects 4-surface box from explicit config/readout flags (`poynting_box`, `v2_box`, `tau_box`, `invariants`), or the simultaneous presence of monitors across all 4 cardinal directions.
2. **Box Closure Gate (Check 5a)**:
   Executed before the universal passivity inequality. For lossless structures with a 4-surface box, verifies that all 4 surfaces are present (raising `poynting_box_unclosed` if any face is missing), extracts fluxes from unforgeable kernel telemetry (`solver_telemetry.json`), and evaluates:
   $$R_{\text{box}} = \left| \frac{\Phi_{\text{out}}}{\Phi_{\text{inc}}} - 1 \right| \le \tau_{\text{box}} \quad (10^{-5})$$
   Rejects deviations with `poynting box closure failure (poynting_box_unclosed)` triggering exit `66`.
3. **Universal Passivity Gate (Check 5b)**:
   Enforces $\sum P_{\text{out}} \le 1.0 + \tau_{\text{pml}}$ on lossless media, raising `passivity_violation` if breached.
4. **Time-Domain Spectral Convergence Gate (Check 6, `V2-decay`)**:
   Enforces $E(T_{\text{end}}) / E_{\max} \le \text{decay\_floor}$ ($10^{-6}$). Truncated simulations trigger refusal with exit `66` (`under_converged_time`).
5. **Certificate Schema Extension**:
   Records `box_closure_residual`, `box_closure_passed`, `box_monitors` (breakdown of `trans`, `refl`, `up`, `down`, `sum`), `decay_ratio`, `energy_decay_ratio`, and `spectral_decay_passed` into `verification_certificate.json`. Adds verification tags:
   - `'verified:v2_box_closure'`
   - `'verified:poynting_box_closed'`
   - `'verified:v2_decay'`
   - `'verified:spectral_decay'`
6. **Granular Postflight Status Emission**:
   Exception handling categorizes failures into distinct statuses:
   - `under_converged_time`: Premature truncation / incomplete pulse decay.
   - `poynting_box_unclosed`: Incomplete 4-surface enclosure or flux closure error $> 10^{-5}$.
   - `passivity_violation`: Outward power exceeding $1.0 + \tau_{\text{pml}}$.
   - `tamper_detected`: Permittivity hash mismatch, flux tampering, or missing telemetry.

### 2.3 Dynamic Postflight Failure Status in `tools/launch.py`
Updated `tools/launch.py` to inspect `run / 'verification_certificate.json'` upon postflight check failure:
```python
if result.returncode != 0:
    rc = 66
    post_status = 'tamper_detected'
    cert_file = run / 'verification_certificate.json'
    if cert_file.is_file():
        try:
            cert_data = json.loads(cert_file.read_text(encoding='utf-8'))
            post_status = cert_data.get('status', 'tamper_detected')
        except Exception:
            pass
    status = f'failed:postflight={post_status}'
    message = f'[run.sh] postflight failed: {check.name} (exit={result.returncode}, status={status})'
    log.write(message + '\n')
    print(message, flush=True)
    break
```
This dynamically sets `manifest['status']`, `run/status`, and `runs/ledger.jsonl` to `failed:postflight=poynting_box_unclosed`, `failed:postflight=under_converged_time`, `failed:postflight=passivity_violation`, or `failed:postflight=tamper_detected`.
