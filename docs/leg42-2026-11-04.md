## 1. Context and Problem Statement

Following the approval of the Agent-Oriented FDTD Platform v4 specification (`spec-agent-fdtd-platform-v4.md`), Wave A establishes a zero-trust execution and notarisation pipeline. Prior to LEG 42, three defects compromised platform integrity and execution:

1. **Deleted Probe Fixtures (Evidence Gap)**:
   Five fixture files under `checks/fixtures/leg27-negative-control-probe/probe-root/runs/` were deleted, breaking `checks/test_leg27_evidence_gaps.py` with 34 test failures. There was no integrity watchdog protecting test fixtures against silent deletion or tampering.

2. **`git -C` Upward Traversal Vulnerability**:
   `checks/pre_environment.py` and `tools/launch.py` invoked `git -C <solver_path> ...` without verifying repository boundaries. In Git's design, `-C <path>` searches parent directories if `<path>` lacks an independent `.git` directory. When `src/torchfdtd` or `src/torchfdtd_upstream` was a plain directory copy without `.git`, Git traversed upward to `torchfdtd-platform`, leaking the platform's git commit hash and dirty status into simulation metadata (`manifest.json`, `runs/ledger.jsonl`). Additionally, `pre_environment.py` crashed on unhandled `AssertionError` instead of returning a clean refusal exit code `65`.

3. **Unconfigured WSL2 Python Environment & Import Failures**:
   Ubuntu 24.04 WSL2 strictly enforces PEP 668, blocking global pip package installation. Without `.venv`, `tools/run.sh` refused execution with exit code `69`. Furthermore, crucial packages (`torch` with CUDA runtime, `numpy`, `scipy`, `matplotlib`, `mcp`, `pydantic`, `fastapi`, `uvicorn`, `fdtd`, `h5py`, `psutil`) were absent, causing widespread import errors across `checks/` and `mcptests/`.

### 2.2 `git -C` Upward Traversal Hardening
Implemented strict boundary validation per `PROJECT.md:71-75`:

```python
def check_solver_git(solver_path):
    solver = Path(solver_path).resolve()
    try:
        top = git(solver, 'rev-parse', '--show-toplevel')
    except (OSError, subprocess.CalledProcessError) as error:
        raise RuntimeError(f'{solver} is not a git repository ({error})') from error
    if Path(top).resolve() != solver:
        raise RuntimeError(f'Git upward traversal detected: {solver} is inside {top}')
    commit = git(solver, 'rev-parse', 'HEAD')
    dirty = git(solver, 'status', '--porcelain')
    changed = len([line for line in dirty.splitlines() if line.strip()])
    return {'commit': commit, 'dirty_lines': changed, 'toplevel': str(Path(top).resolve())}
```

- **`checks/pre_environment.py`**:
  - `check_upstream(pin, required=True)`: Invokes `check_solver_git(up)`. When required, an un-repo'd or upward-traversed directory cleanly refuses with exit code `65`. In read-only audit mode (`required=False`), records upstream as unavailable with descriptive log output and avoids crashing on `AssertionError: FROZEN UPSTREAM MOVED`.
  - `check_fork(pin)`: Invokes `check_solver_git(fork)`. Refuses with exit code `65` and prints actionable message to `sys.stderr` when fork lacks independent `.git`.
- **`tools/launch.py`**:
  - Guarded tree copy: `if (solver / 'torchfdtd').is_dir():` prevents `FileNotFoundError` prior to preflight checks.
  - Helper `_solver_is_repo(path)`: Compares `Path(top).resolve() == Path(path).resolve()`. If false, `_solver_commit` returns `'unavailable'` and `_solver_dirty_lines` returns `0`, preventing platform commit/dirty leaks into `manifest.json`.
  - Preflight defense: Refuses un-repo'd solver with exit code `65` before spawning simulation processes.
- **Downstream Mock Updates**:
  - `checks/test_driver_contracts.py:git_output`: Added branch for `['rev-parse', '--show-toplevel']` returning `str(Path(args[2]).resolve()) + '\n'`.
  - `mcp_server/validation.py:check_output`: Added branch for `['rev-parse', '--show-toplevel']` returning `str(path.resolve()) + '\n'`.
- **Latent Fixture Fix in `mcptests/support.py`**:
  `_fake_solver(path)` previously invoked `_git(path.parent, 'init', '-q')`, initializing Git in `src/` rather than `src/torchfdtd/`. Corrected to `_git(path, 'init', '-q')`, aligning test fixtures with the strict independent repository contract.
