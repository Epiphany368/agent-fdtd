## 2. Technical Architecture & Physics Formulations

### 2.1 M3 Filter and Differentiable Projection
To satisfy industrial fabrication limits, density distribution $\rho(x) \in [0, 1]$ is regularized through a three-tier enforcement hierarchy:
1. **Tier 1: Conic Spatial Filtering & Smooth Tanh Projection**:
   Conic filter kernel of radius $R \ge 150\text{ nm}$:
   $$K(x, x') = \max\left(0, 1 - \frac{|x - x'|}{R}\right), \quad \sum_{x'} K(x, x') = 1$$
   $$\tilde{\rho}(x) = \sum_{x'} K(x, x') \rho(x')$$
   Modified threshold projection with continuation parameter $\beta$:
   $$\bar{\rho}(x) = \frac{\tanh(\beta \eta) + \tanh(\beta (\tilde{\rho}(x) - \eta))}{\tanh(\beta \eta) + \tanh(\beta (1 - \eta))}$$
   Differentiable permittivity mapping:
   $$\varepsilon(x) = \varepsilon_{\text{clad}} + (\varepsilon_{\text{core}} - \varepsilon_{\text{clad}}) \bar{\rho}(x)$$

2. **Tier 2: Differentiable M3 Penalty ($P_{M3}$)**:
   Penalizes intermediate binarization non-compliance and sub-resolution features:
   $$P_{M3}(\rho) = \frac{1}{N} \sum_{i} 4 \bar{\rho}_i (1 - \bar{\rho}_i) + \alpha \sum_i \max\left(0, \frac{\Delta x}{R} - |\bar{\rho}_{i+1} - \bar{\rho}_i|\right)^2$$

3. **Tier 3: Discrete Morphological Projection**:
   Guarantees zero fabrication violations in discrete geometry:
   $$\mathbf{b} = \operatorname{round}(\bar{\rho}) \in \{0, 1\}^N$$
   $$\mathbf{b}_{\text{proj}} = \operatorname{close}(\operatorname{open}(\mathbf{b}, m), m), \quad m = \lceil R / \Delta x \rceil \text{ cells}$$
   Evaluated with `torchfdtd.fabrication.FeatureSizes(min_linewidth_um=0.150, min_gap_um=0.150).violations()` yielding strictly $0$ violations.

### 2.2 Exact Analytic Jacobian & Finite Difference Check
The analytic derivative is derived via chain rule:
$$\frac{\partial \varepsilon}{\partial \rho} = \operatorname{diag}\left(\frac{\partial \varepsilon}{\partial \bar{\rho}} \frac{\partial \bar{\rho}}{\partial \tilde{\rho}}\right) K$$
where:
$$\frac{\partial \bar{\rho}}{\partial \tilde{\rho}} = \frac{\beta (1 - \tanh^2(\beta (\tilde{\rho} - \eta)))}{\tanh(\beta \eta) + \tanh(\beta (1 - \eta))}$$
Analytic Jacobian is verified against two-sided numerical finite differences:
$$J_{\text{num}, j} = \frac{\varepsilon(\rho + h e_j) - \varepsilon(\rho - h e_j)}{2h}, \quad h = 10^{-6}$$
$$\text{Relative Error} = \frac{\|J_{\text{analytic}} - J_{\text{num}}\|_\infty}{\|J_{\text{num}}\|_\infty} \le 10^{-6}$$
Measured across all test sweeps: **$1.692 \times 10^{-9} \ll 10^{-6}$** (error margin $> 500\times$).

### 2.3 Closed Forward-Adjoint Optimization on Canonical 2D SOI Grating
The optimization loop drives a 2D SOI grating coupler test vehicle:
- Core silicon $n_{\text{core}} = 3.477$, cladding $n_{\text{clad}} = 1.444$, wavelength $\lambda_0 = 1.55\,\mu\text{m}$.
- Objective function: upward Poynting flux through top monitor surface normalized by unperturbed reference waveguide flux:
  $$J(\rho) = \frac{P_{\text{top}}(\rho)}{P_{\text{ref}}}$$
- Adjoint source injection and automatic differentiation yields gradient:
  $$\nabla_\rho J = \left(\frac{\partial \varepsilon}{\partial \rho}\right)^T \frac{\partial J}{\partial \varepsilon}$$
- Update via Adam / Projected Gradient Ascent with Armijo backtracking line search to ensure monotonic ascent $\Delta J \ge 0$.
